## 今天做完的事

上游返回非 2xx 时，`chat()` 之前的 `.error_for_status()` 把响应正文整体丢掉，401（鉴权失败）、额度不足、
限流、参数非法在日志和界面上长得一模一样，roadmap 阶段 3 要求的「上游 error 在前端可见」无法验证。

现在：

1. 非 2xx → 新错误变体 `ChatError::Upstream { status, message }`；
2. `message` 优先取上游 `error.message`，网关返回 HTML/纯文本时退化为正文原文，正文为空给固定文案；
3. `sk-` 开头的令牌先打码成 `sk-***`，再按**字符**截断到 300 字符（按字节切会切坏中文并 panic）；
4. 成功路径抽成 `completion_text()`，行为与改动前一致（仍只取 `choices[0].message.content`）。
