## 今天做完的事

右侧 diff 面板的解析有两个会「说假话」的缺陷：

1. **末尾幻影行**：`git diff` 文本以 `\n` 结尾，`split("\n")` 多出的空串被当成上下文行 push 进去，
   面板每个文件末尾都多一行空白，而且它带着递增行号，看起来像行号错位。
2. **增删计数漏计**：`diffStats` 用 `startsWith("+++") / startsWith("---")` 判断文件头，
   hunk 内以 `--` / `++` 开头的正文（例如删除 `--old` → diff 行是 `---old`）被当成文件头跳过，
   `+N/−M` 徽标小于实际。

修法：把三个纯函数（`DiffRow` 类型、`diffStats`、`parseUnifiedDiff`）从 `core/workspace.ts` 迁到
**零 import 的 `core/diff.ts`**（可被 `node --experimental-strip-types` 直接导入做离线校验），并把判定改为：

- 文件头只在**首个 hunk 之前**跳过（用 `inHunk` 状态位），hunk 内 `-`/`+` 开头一律按正文处理；
- 只有**最后一个**空串（末尾换行）被跳过，不误伤 hunk 内真实的空上下文行；
- `workspace.ts` 改为 re-export，`DiffSidebar.tsx` 的导入路径与公开 API 一字未动。
